# Assets Folder

This folder should contain the following image assets for the application:

## Required Assets

Create these placeholder images (or use actual designs):

1. **Square44x44Logo.png** (44x44 pixels)
   - App icon in task manager and taskbar

2. **Square150x150Logo.png** (150x150 pixels)
   - Start menu tile

3. **Wide310x150Logo.png** (310x150 pixels)
   - Wide start menu tile

4. **StoreLogo.png** (50x50 pixels)
   - Microsoft Store logo

5. **SplashScreen.png** (620x300 pixels)
   - Shown during app launch
